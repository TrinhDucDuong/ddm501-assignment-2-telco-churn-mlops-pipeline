The project does not claim a prospective or causal business evaluation.

The upstream repository license is included as `LICENSE-source.txt`. Retain source attribution when redistributing the sample. All inputs and outputs in the submitted prototype relate to this public sample; do not replace it with private customer data in a public Git repository.
